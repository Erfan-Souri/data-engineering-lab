# ClickHouse Distributed Lab

## Overview

This lab extends the replicated ClickHouse cluster by introducing sharding and distributed query execution.

The objective is to understand how ClickHouse distributes data across multiple shards while maintaining replication for high availability.

---

## Objectives

- Build a multi-shard ClickHouse cluster
- Understand the Distributed engine
- Explore data sharding
- Execute distributed analytical queries
- Compare replication and sharding
