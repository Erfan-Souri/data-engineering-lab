# ClickHouse Lab

## Overview

This lab introduces ClickHouse using Docker Compose.

The objective is to understand how ClickHouse differs from PostgreSQL and to build a foundation for analytical workloads.

---

## Objectives

- Deploy ClickHouse with Docker Compose
- Understand the ClickHouse server and client
- Learn MergeTree tables
- Explore column-oriented storage
- Practice analytical SQL queries
- Compare ClickHouse with PostgreSQL
