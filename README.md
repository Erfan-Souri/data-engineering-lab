# Data Engineering Lab

This repository documents my journey of building a personal data engineering lab from scratch.

The goal is to strengthen my understanding of Docker, PostgreSQL, ClickHouse, distributed systems, ETL pipelines, and modern data engineering practices through hands-on experimentation.

Rather than following isolated tutorials, this repository grows incrementally as I learn, experiment, and document the reasoning behind each step.

## Current Progress

- ✅ Docker Desktop
- ✅ PostgreSQL in Docker
- ✅ Persistent Docker Volumes

## Planned Topics

- Docker Compose
- ClickHouse
- MongoDB
- Apache NiFi
- HAProxy
- Monitoring
- Kubernetes

## Philosophy

Every component added to this lab is documented and understood before moving to the next one.

The objective is not only to build working systems, but also to understand why they work.
